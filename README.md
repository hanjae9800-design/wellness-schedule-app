# 프로젝트 추진일정 (실시간 협업 버전)

Supabase(실시간 DB) + Cloudflare Pages로 배포되는 독립 웹앱입니다.
클로드 아티팩트와 달리 링크만 있으면 비밀번호 없이 누구나 바로 실시간으로 함께 수정할 수 있습니다.

## 로컬에서 미리보기

빌드 도구 없이 순수 HTML/CSS/JS라, 아무 정적 서버로나 열면 됩니다.

```
npx --yes serve .
```

## 배포 전 준비

1. `supabase-schema.sql`을 Supabase 대시보드 > SQL Editor에서 실행 (테이블 생성 + 실시간 활성화)
2. Cloudflare Pages에 이 폴더 전체를 배포 (빌드 명령 없음, 정적 파일 그대로 배포)

## 보안 참고

- Supabase anon key는 공개되어도 안전하도록 설계된 키이며, 실제 접근 제어는 데이터베이스의 RLS(Row Level Security) 정책이 담당합니다.
- 비밀번호 게이트가 없으므로, 이 링크를 아는 사람은 누구나 즉시 데이터를 읽고 수정할 수 있습니다. 민감한 정보를 담지 않는 내부 일정 공유용으로만 사용하세요.
