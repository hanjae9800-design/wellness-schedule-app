# 프로젝트 추진일정 (실시간 협업 버전)

Supabase(실시간 DB) + Cloudflare Pages로 배포되는 독립 웹앱입니다.
클로드 아티팩트와 달리 링크만 있으면(팀 공용 비밀번호 입력 후) 누구나 실시간으로 함께 수정할 수 있습니다.

## 로컬에서 미리보기

빌드 도구 없이 순수 HTML/CSS/JS라, 아무 정적 서버로나 열면 됩니다.

```
npx --yes serve .
```

## 배포 전 준비

1. `supabase-schema.sql`을 Supabase 대시보드 > SQL Editor에서 실행 (테이블 생성 + 실시간 활성화)
2. `config.js`의 `TEAM_PASSWORD`를 실제 팀 공용 비밀번호로 변경
3. Cloudflare Pages에 이 폴더 전체를 배포 (빌드 명령 없음, 정적 파일 그대로 배포)

## 보안 참고

- Supabase anon key는 공개되어도 안전하도록 설계된 키이며, 실제 접근 제어는 데이터베이스의 RLS(Row Level Security) 정책이 담당합니다.
- 화면의 팀 공용 비밀번호는 실수로 아무나 수정하는 것을 막는 화면단 게이트일 뿐, 암호학적 보안이 아닙니다. 페이지 소스를 보면 비밀번호 문자열이 그대로 노출됩니다. 민감한 정보를 담지 않는 내부 일정 공유용으로만 사용하세요.
